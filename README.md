# Personal research website

Plain HTML, no build step.

## Publish on GitHub Pages
1. On GitHub, create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder (including `.nojekyll`) to the repository root.
3. Repository Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/`.

The preconception poster page will be at `/posters/preconception-messaging/`. Use that address for the QR code.
