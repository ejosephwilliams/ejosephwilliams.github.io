# Personal research website

Plain HTML, no build step.

## Publish on GitHub Pages
1. On GitHub, create a **public** repository named `ejosephwilliams.github.io`.
2. Upload everything in this folder (including `.nojekyll`) to the repository root.
3. Repository Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at `https://ejosephwilliams.github.io/`.

Poster pages: `/posters/preconception-messaging/`, `/posters/employment-precarity/` and `/posters/social-support-buffering/`.
